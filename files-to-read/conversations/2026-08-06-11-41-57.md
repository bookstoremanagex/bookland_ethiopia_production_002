## Summary
Implemented the "Edit Order" feature for pending orders in the admin Manage Orders detail modal.

## Key decisions
- Edit reuses the shared `OrderModal` (create-order UI) in edit mode.
- Updates the same order in place (keeps ORD id, stays pending). Only for `!order.is_approved`.
- Re-runs FIFO at current selling prices; manual total override still supported.
- Excludes the order's own locked stock so current quantities stay valid.
- New order items/locks replace old ones inside a transaction.
